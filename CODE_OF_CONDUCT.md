# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about the work. Harassment or personal attacks aren't tolerated.

Report problems privately to the maintainer through GitHub (the repository owner's profile), or via **Security → Report a vulnerability** if you need a private channel. Reports are handled confidentially.
